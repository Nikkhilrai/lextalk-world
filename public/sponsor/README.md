## Required Images:

1. **premium-networking.jpg** (or .png/.avif)
   - Recommended size: 1600x900px (16:9 aspect ratio)
   - Content: Image showing premium networking event, executives talking, etc.

2. **product-showcases.jpg** (or .png/.avif)
   - Recommended size: 1600x900px (16:9 aspect ratio)
   - Content: Image showing product demos, exhibition booths, tech showcases, etc.

## How to use:
1. Upload your images to: `/public/sponsor/`
2. Name them exactly as listed above
3. The website will automatically display them in the "Why Sponsorship Works?" section
